## 浏览器回归复现

`scripts/browser-smoke.cjs` 使用 Playwright，运行目标必须是刚初始化的独立 demo 数据库：脚本会注册 `newstudent`、核验虚构学号、取消示例活动并覆盖展示截图。它不能用于真实业务实例。启动应用后，在已安装 Playwright 和浏览器的环境运行：

```bash
node scripts/browser-smoke.cjs
```

可设置 `PLAYWRIGHT_MODULE` 指向现有 Playwright 安装、`BROWSER_CHANNEL=msedge` 使用已安装的 Edge，或设置 `APP_URL` 指向本地隔离实例。默认使用 Chromium。前端无 npm 构建要求，Playwright 只是可选回归工具。
